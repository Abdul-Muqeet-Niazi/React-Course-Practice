# React Learning Journey

Learning React step by step, starting with **JavaScript for React, JSX, components, props, state, events, forms, lists, conditional rendering, styling, hooks, useEffect, data fetching, custom hooks,** and **understanding how React works behind the scenes**.

Then moving into advanced React with **useReducer, Context API, React Router, Redux & Redux Toolkit, asynchronous actions, React Query, authentication, protected routes, performance optimization, memoization, reusable components, compound components, React Hook Form, Supabase, charts, dark mode, deployment, Next.js, server-side rendering, React Server Components,** and **building complete real-world applications**.

## Learning Stages

**Stage 1** — **JavaScript & React Basics:** Modern JavaScript, ES6+, JSX, components, props, state, events, conditional rendering, lists, and styling.
